# Run locally

This project is meant to be developed and previewed on your machine — not only in Cursor Cloud.

## Setup

```bash
cd lab
npm install
npm run dev
```

Open **http://localhost:3000/demos/tyler-glass-nav**

Stub routes (same demo, remounts at peek): `?r=/` · `?r=/work` · `?r=/contact`

## Quality checks

```bash
cd lab
npm run lint
npm run build
```

`lab/src/components/projects/navigation/tyler-glass-nav/`
