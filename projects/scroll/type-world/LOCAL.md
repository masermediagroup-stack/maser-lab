# Local notes — TYPE WORLD

Demo: `/demos/type-world`

Tune quote, ink, drag, inertia, pitch, auto yaw, and spherical surface effects from the demo Leva panel. Defaults stay empty-field editorial — the world turns slowly until grabbed. Surface Effect defaults to Orbs so the existing compositor look is preserved.

WebGL fallback and reduced-motion can be forced from demo controls without DevTools. Reduced motion freezes gradient travel, shader `uTime`, and orb glide; the selected effect remains visible.
