# Run locally

This project is meant to be developed and previewed on your machine — not only in Cursor Cloud.

## Setup

```bash
cd lab
npm install
npm run dev
```

Open **http://localhost:3000/demos/chromemark**

## Quality checks

```bash
cd lab
npm run lint
npm run build
```

## Component path

`lab/src/components/projects/web-apps/chromemark/`

## Spec

`projects/web-apps/chromemark/PROJECT.md`
