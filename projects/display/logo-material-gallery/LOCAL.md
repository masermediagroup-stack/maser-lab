# Run locally

This project is meant to be developed and previewed on your machine — not only in Cursor Cloud.

## Setup

```bash
cd lab
npm run dev
```

From repo root: `npm run dev`.

Open **http://localhost:3000/demos/logo-material-gallery**

## Quality checks

```bash
cd lab
npm run lint
npm run build
```

## Component path

`lab/src/components/projects/display/logo-material-gallery/`

## Spec

`projects/display/logo-material-gallery/PROJECT.md`
