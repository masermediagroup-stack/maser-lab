## Stub promotion gate (hard)

If the PR touches a stubbed roadmap domain (assets, preset redesign, new engine, …):

- [ ] Matching `docs/roadmap/0N-*.md` promoted from stub → full depth for what shipped
- [ ] Cross-links updated from [README](./README.md)

Horizon ideas in [11](./11-V2-FUTURE.md) **never** waive sacred engine contracts.

## Every engine/shader change

- [ ] `/demos/maser-dither-engine` Overview + Playground show **non-black** dithered surface
- [ ] Material ID switch + dither algorithm switch — no `Shader compile error`
- [ ] Reduced motion: CRT flicker muted; surfaces still render
- [ ] Materials page: thumbs CSS (or blit); detail ≤ one live canvas
- [ ] `cd lab && npm run lint && npm run build`

## v1.0 release checklist

- [ ] Public/product barrel frozen (no shell / no `--lab-*`)
- [ ] Local `npm pack` + install smoke ([06](./06-EXPORT-SYSTEM.md))
- [ ] `TRANSFER.md` complete
- [ ] `maser-lab-acceptance-audit` pass
- [ ] `maser-lab-export` pass
- [ ] Registry status → `ready` only after above
- [ ] Roadmap stubs for touched domains promoted
- [ ] Responsive spot-check 320 / 1280 on key adapters
