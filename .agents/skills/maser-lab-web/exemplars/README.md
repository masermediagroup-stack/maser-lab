# Exemplars

Document shipped project decisions worth repeating — and mistakes to avoid.

Each exemplar uses Decision-template fields plus:

- **Useful decisions** — patterns agents may reuse with evidence
- **Known flaws** — do **not** copy; shipped code is evidence, not automatic precedent
- **Sources** — PR / demo / commit / project docs

Format: `pr-{slug}.md`
